Balanced ternary · live sketch

Rubber band, then quicksand.

Each tick the drift is a trit: −1 below, 0 inside a dead band, or +1 above. Outside the band a rubber band pulls harder the further it stretches. Quicksand is drag that grows with speed, and inside the band it holds the value nearly still.

The step

  1. error = position − target
  2. trit = −1 if error < −band, +1 if error > band, else 0
  3. rubber = trit ≠ 0 ? −stiffness × error : 0
  4. quicksand = −c × velocity × (1 + |velocity|) with c = thickness, or c = thickness × 4 when the trit is 0
  5. velocity += (rubber + noise) × dt, then quicksand removes speed without flipping it
  6. position += velocity × dt

Lane A uses only the noise. Lane B adds the rubber band. Lane C adds both. Drop thickness to 0 and lane C starts swinging like lane B. The three lanes hear one shared kick per tick, so the difference is the damping, not the weather. Reset puts every lane back at +2.20 with no speed.

Assumptions in this sketch
  • The target is fixed at 0. The dead-band slider is a half-width, and the edge counts as trit 0.
  • Noise is one uniform acceleration in [−noise, +noise], reused by all three lanes.
  • The rubber force follows the full error, not only the distance past the band, and it is off on trit 0. Inside the band the value is not chased to the center.
  • Quicksand is linear drag plus a speed-squared term, so a fast swing bogs down harder than a creep. Inside the band it is four times thicker.
  • The integrator is semi-implicit Euler at a fixed 30 steps per second. Drag is clamped so one tick cannot reverse velocity.
  • Reset replays the same noise seed, from the same offset, so the settling comparison is repeatable.
